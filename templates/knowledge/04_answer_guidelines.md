# 답변 생성 지침 (반드시 따를 것)

1. **답변은 최대한 짧게.** 영어 답변은 1~2문장, 단답이 가능하면 단답으로.
   (좋은 예: "No. We sort all parts internally." / "About 17 million won." / "Yes, it is complete.")
   질문받은 것에만 답하고 배경 설명은 붙이지 않는다. 쉬운 단어만 쓴다.
2. 준비된 답변(02 파일)이 길어도 그대로 다 쓰지 말고, 질문에 해당하는 문장만 골라 짧게 답한다.
   자료에 없는 상세를 요구하는 부분만 아래 "이메일 후속 문장"으로 마무리한다.
3. 이메일 후속 문장 (자료에 없거나 확신이 없을 때 영어 답변의 마지막 문장으로 사용):
   - "Let me confirm and follow up by email."
   - 또는: "I understand the question — I just want to make sure my answer is accurate, so I'll send it by email."
4. 절대 수치를 지어내지 않는다. 자료에 없는 숫자는 말하지 않는다.
5. 발표자가 즐겨 쓰는 만능 문장 (질문이 전혀 이해 안 되거나 자료 밖일 때 통째로 사용):
   - 영어: "I understand the question. I just want to make sure my answer is accurate, so I'll send the details by email after the meeting."
   - 한국어 의미: 질문은 이해했고, 정확한 답을 위해 회의 후 이메일로 상세히 회신하겠다.

## 용어집 (전사 오류 대비 — 발음이 비슷하게 깨져도 아래 용어로 해석할 것)
- COPQ = Cost of Poor Quality (씨오피큐, 코프큐 등으로 들릴 수 있음)
- SVP = 매출 기준값 (% of SVP로 지표 산출)
- JEO = 공장 이름 (한국). "제이이오", "지오" 등으로 들릴 수 있음
- generator / gas generator / sintering generator / reformer = 모두 같은 설비 = **변성로**
  (슬라이드와 발표에서는 "generator"로 부름. 답변에서도 generator를 쓸 것)
- sintering = 소결 공정. "신터링"
- TM Part / Transmission Part = Team2 담당 제품 (수량 적고 개당 단가 높음)
- VMS Part = Team1 담당 제품 (수량 많고 개당 단가 낮음)
- Mando / 만도 = 고객사 이름. "만도", "맨도" 등
- damping force = 댐핑 포스 = 감쇄력 (만도 이슈 관련)
- Self Body / TM985 = 만도 이슈 제품명. "셀프 바디", "티엠 나인 에이티 파이브" 등
- compacting = **성형 공정** (만도 건 crack 발생 공정. "forming"이 아니라 compacting으로 말할 것)
- tolerance = (금형 제작) 공차. "톨러런스"
- mold / tooling = 금형
- warranty / sorting cost = 워런티/선별 비용 (슬라이드 4)
- GMK / ZF Austria / Mando MBC = 고객사 이름
- NTF = Not Trouble Found (점검 결과 이상 없음)
- springback = 스프링백 (compacting 성형 후 되튀는 현상)
- NDI = 비파괴검사 (Non-Destructive Inspection)
- pulley = 풀리 (ZF 녹 이슈 제품)
- oil leak = 오일 누유 (crack 부위로 발생)
- carrier scrap = 캐리어 스크랩 (변성로 고장으로 발생)
- endo gas = 엔도 가스, 흡열형 가스 (변성로가 생산, 소결로 분위기 형성)
- atmosphere = (소결로 내) 분위기 가스
- brazing material / filler = 브레이징제 (접합용 용가재)
- 3rd party containment = 서드파티 컨테인먼트 (외부 선별 비용)
- PM = Preventive Maintenance (예방 정비)
- MKRW = 백만원 (million KRW)
- YTD = Year-to-Date (연초 누계)
