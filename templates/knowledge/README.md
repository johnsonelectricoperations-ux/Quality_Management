# knowledge 폴더 사용법

이 폴더에 **답변의 근거가 될 자료**를 `.md` 또는 `.txt` 파일로 넣으세요.

- 발표 대본 (영어/한국어 아무거나)
- 보고 내용 상세 (수치, 일정, 담당자 등)
- 예상 질문과 준비된 답변
- 답하면 안 되는 것 / 조심할 표현이 있으면 그것도 적어두세요
  (예: "원가 관련 수치는 구체적으로 말하지 말 것")

파일 여러 개로 나눠도 되고 하나에 다 넣어도 됩니다.
**질문할 때마다 파일을 새로 읽으므로, 회의 직전이나 도중에 수정해도 바로 반영됩니다.**

`sample.md`는 형식 예시입니다. 실제 자료를 넣은 뒤 지워도 됩니다.

⚠️ 이 폴더의 파일은 git에 올라가지 않습니다 (`sample.md`와 이 안내문 제외).
회사 자료가 저장소에 커밋되는 것을 막기 위한 설정입니다.
