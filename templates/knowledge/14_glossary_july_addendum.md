# 용어집 추가분 — 2026년 7월 신규 이슈 관련

`04_answer_guidelines.md`의 용어집에 이어서 적용할 것. (기존 용어집은 그대로 유효)

## 7월 신규 용어

- **동심도 / concentricity** = 부품 안쪽 원과 바깥쪽 원의 중심 일치도. "동심도", "콘센트리시티"
- **Pulley / 풀리** = 7월 수량 1위 이슈 제품. Ball Nut Pulley(2206), Motor Pulley(1360, 1785),
  Belt Pulley(2059)
- **Feeder / 피더** = 성형 프레스에서 분말을 금형 Cavity에 채워 넣는 장치
- **Feeder System 변경** = 4/22 시행. 동심도 이슈의 배경 요인 중 하나
- **Die-set / 다이셋** = 금형 세트. "하 1단 / 하 2단"은 하부 다이셋 구성 방식
  (5/6 하2단 적용 → Core 낌 발생 → 7/14 하1단 원복)
- **Core 낌** = 금형 코어부가 걸리는 현상. 동심도 틀어짐의 원인
- **전진속도 / advance speed** = Feeder가 금형으로 전진하는 속도. 270 → 320 mm/s로 변경
- **충진 시간 / filling time** = 분말이 Cavity에 채워지는 시간. 0.417초 → 0.519초 (23% 증가)
- **SPM** = Strokes Per Minute (분당 프레스 타발 수). 현재 양산 조건 SPM 10.0
- **JHC100/6** = Pulley 성형 프레스 설비명. "제이에이치씨 백육"
- **정형 / sizing** = 성형·소결 후 치수를 잡는 공정. 동심도 불량의 **발견** 공정
- **성형 / compacting** = 분말을 금형에서 압축 성형하는 공정. 동심도 불량의 **원인** 공정
- **면취부 크랙 / chamfer crack** = 7월 비용 2위 이슈(2059-00 Belt Pulley). 상세 원인 미확보
- **ABBOTT 36"/3** = Carrier 브레이징 이슈가 발생한 소결로 설비명
- **냉각대 / cooling coil** = 변성로의 가스 냉각 부위. Crack으로 수분 유입 발생
- **Ni 촉매** = 변성로에서 endo gas를 만드는 촉매. 냉각대 교체 시 전량 교환
- **Retort** = 변성로 내 반응 용기
- **C/Sheet / 체크시트** = Check Sheet, 현장 점검 기록지
- **정전폐기 / power outage scrap** = 7/22 정전으로 발생한 폐기 2,435EA. **비용 0원으로 집계됨**
  (품번 미지정이라 단가를 붙일 수 없음)
- **HMC 8속** = 현대차 8단 변속기. Carrier 4종이 이 차종용
- **외주 소결불량** = 6월 비용 1위(14.2백만원) 항목. **7월에는 0원으로 완전 해소**
- **품번 미지정** = TM-NO가 지정되지 않은 불량 건. 수량에는 반영되나 **비용은 0원**

## 7월 답변 시 특별 주의사항

1. **"수량 1위 = 비용 1위"가 아니다.**
   - 수량 1위 = Pulley 동심도 (3,880EA, 비용은 5%)
   - 비용 1위 = Carrier 브레이징 (10.1백만원)
   - 비용 2위 = Belt Pulley 면취부 크랙 (7.2백만원)
   - COPQ·스크랩비용 질문에는 **비용 기준**으로 답할 것.

2. **면취부 크랙(2059-00)은 8D 보고서가 없다.** 원인·대책을 지어내지 말고
   "확인 후 이메일 회신"으로 처리할 것.

3. **7월 고객비용은 0원이다.** 만도 damping force(9백만원)는 6월 건이므로 섞지 말 것.

4. **7월은 수량 목표도 미달이다.** 6월 대본의 "we achieved this target"을 그대로 쓰면 안 됨.

5. **정전폐기 비용 0원**은 시스템 집계 규칙 때문이며, 실제 손실이 없다는 뜻이 아니다.
   이 점을 물으면 솔직하게 "실제 손실은 맞다"고 인정하고 이메일 회신으로 마무리할 것.
